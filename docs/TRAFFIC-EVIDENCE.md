# ข้อมูลจราจรระดับประเทศ

ตัวดึง DOH และ DRR รับพิกัดทั่วประเทศไทยและจับคู่ภายในรัศมีวิเคราะห์ ไม่จำกัดจังหวัด หากมี AADT หลายแหล่ง จะเลือกปีใหม่กว่าก่อน แล้วเลือกแนวถนนที่ใกล้กว่า การเลือกยังเป็นข้อมูลบริเวณโดยรอบ ไม่ยืนยันรถที่ผ่านทางเข้าแปลง ถนนยกระดับหรือถนนฝั่งตรงข้ามอาจเข้าแปลงไม่ได้

ลำดับผล: AADT ทางการ → จุดสำรวจท้องถิ่นที่จัดเตรียมไว้ → ศักยภาพถนน OSM → ไม่มีหลักฐานที่ใช้ได้ สถานะตรวจสอบรายแหล่งถูกเก็บกับผลวิเคราะห์ใหม่ แยกดึงข้อมูลล้มเหลวออกจากค้นหาแล้วไม่พบ ArcGIS HTTP 200 ที่มี error จะไม่ถูกเก็บเป็นผลค้นหาว่าง และอ่านข้อมูลจนครบทุกหน้า

OSM เป็นคะแนนตามสูตรที่ตั้งไว้ ยังไม่มีการสอบเทียบกับจำนวนรถจริง ไม่ควรตีความคะแนนเป็นเปอร์เซ็นต์ความแม่นยำหรือจำนวนคัน/วัน ผลนับรถท้องถิ่นที่หน่วยต่างจาก AADT ไม่เข้าไปในสูตรคะแนน AADT

## เชื่อมผลสำรวจจากจังหวัดใดก็ได้

กำหนด `LOCAL_TRAFFIC_CSV_URL` เป็น URL ของ CSV ที่ผู้ดูแลตรวจแหล่งอ้างอิง สิทธิ์ใช้ข้อมูล หน่วย ระยะเวลาสำรวจ และพิกัดจุดนับแล้ว จากนั้นสร้าง API container ใหม่ ค่าเริ่มต้นว่าง ไม่มีการนำข้อมูลจำลองเข้า production และยังไม่มีชุดข้อมูลท้องถิ่นที่เปิดใช้โดยอัตโนมัติ

CSV ต้องมีหัวคอลัมน์:

```csv
station,province,latitude,longitude,value,unit,survey_date,survey_hours,source,reference_url
```

`survey_date` ใช้ YYYY-MM-DD ค.ศ.; `survey_hours` คือระยะเวลานับจริง หน่วย `unit` รองรับ `vehicles/day`, `vehicles/survey`, `PCU/day`, `PCU/hour` ระบบเก็บหน่วยเดิม ไม่แปลงชั่วโมงสำรวจเป็นยอดรายวันหรือ AADT อัตโนมัติ แสดงเฉพาะจุดใกล้สุดภายในระยะที่น้อยกว่าระหว่าง 1 กม. กับรัศมีวิเคราะห์ พร้อมวันที่และระยะทาง ค่าเป็นข้อมูลสำรวจประกอบ (preliminary) จนตรวจความเกี่ยวข้องกับทางเข้าแปลง

## แหล่งอ้างอิงและข้อจำกัด

- DOH: https://datagov.mot.go.th/th/dataset/traf62
- DRR: https://datagov.mot.go.th/th/dataset/aadt1
- บัญชี PCU: https://datagov.mot.go.th/dataset/dataset_12_011 — ทรัพยากร CSV ที่ตรวจพบเป็นรายการลิงก์รายงาน ต้องนำเข้าข้อมูลจากรายงานหลังตรวจสอบ ยังไม่ได้เปิดใช้ PCU อัตโนมัติ
- BMA เป็นข้อมูลเสริมเฉพาะพื้นที่: https://traffic.bangkok.go.th/re_intersection/intersection/intersection.html — ยังต้องจัดเตรียมพิกัดและช่วงสำรวจ

ยังไม่ได้เชื่อม TomTom/Longdo หรือผู้ให้บริการเสียเงิน และไม่ได้รับประกันข้อมูลนับรถครบทุกถนนใน 77 จังหวัด ทดสอบเชิงพื้นที่ด้วย `TRAFFIC_LIVE_AUDIT=1 go test ./internal/provider -run TestTrafficNationalLive -v` ครอบคลุมจุดตัวอย่างกรุงเทพฯ อ่างทอง เชียงใหม่ ขอนแก่น สงขลา ผล no_match ที่ไม่มี source error ถือเป็นช่องว่างข้อมูลจริงในชุดที่เชื่อม ณ เวลาตรวจ
